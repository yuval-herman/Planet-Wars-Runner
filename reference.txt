== PLANET WARS PROTOCOL & MAP QUICK REF ==

[GAME LOOP]
Engine -> Bot: Transmits all P and F lines, terminates with "go".
Bot -> Engine: Transmits 0+ order lines, terminates with "go" (1s limit).
Bot -> stderr: Freely write text at any time; engine ignores it for game state.

[COORDINATE SPACE & DISTANCE]
Format : 2D continuous floating-point space.
Travel : Turns = ceil(sqrt((x1 - x2)^2 + (y1 - y2)^2)).

[DATA TYPES]
<x>, <y>             : Float (Coordinate space)
<owner>              : Integer (0 = Neutral, 1 = Player 1, 2 = Player 2)
<ships>, <growth>    : Integer (Count / Ships generated per turn)
<*_id>               : Integer (0-indexed planet ID based on stream order)
<total>, <remaining> : Integer (Total trip duration / Turns until arrival)

[ENGINE TO BOT (stdin)]
P <x> <y> <owner> <ships> <growth>
F <owner> <ships> <source_id> <dest_id> <total> <remaining>
go

[BOT TO ENGINE (stdout)]
<source_id> <dest_id> <ships>
go

[MAP FILE FORMAT (.txt)]
Lines starting with '#' or empty lines are ignored as comments/whitespace.
Contains P lines (and optionally pre-existing F lines) to initialize state.
Planet ID is determined by the line order (0, 1, 2...) of 'P' entries.

[BOT DEBUGGING (stderr)]
<any text>           : Safely print errors, state logs, or traces here.
